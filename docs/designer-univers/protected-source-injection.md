# Protected Source Rule Injection

All Designer_Univers-derived harnesses must include a common protected source block plus role-specific restrictions.

## Common Block

```markdown
## Protected Source Rules

The following are protected read-only reference sources:

- `Designer Earth/Designer World/_Identity/`
- `Designer Earth/Designer World/_Philosophy/`
- `Designer Earth/Personal Thinking/`
- `Designer_Univers/Personal Inspiration Sources/`
- Eagle raw library data
- `Designer Master/Work Files/` raw originals
- files named or containing `About Me`, `Storytelling_First`, `Background_Before_Design`

Forbidden without explicit user approval:

- modify, delete, move, rename, overwrite, or normalize protected sources
- upload protected originals to external services
- silently promote candidates into official identity/philosophy/pattern documents
- rewrite user voice or philosophy as if it were final truth

Allowed by default:

- read for analysis
- create separate analysis notes under approved run/draft paths
- propose candidates with clear provenance
- request user approval for promotions
```

## Role-Specific Injection

| Agent Class | Extra Rules |
|---|---|
| collector | inventory only; do not classify identity/philosophy as final |
| analyst | cite source paths; distinguish evidence from interpretation |
| creator | create drafts only; never overwrite user-authored originals |
| reviewer | verify boundaries and report violations; no creative rewriting |
| orchestrator | enforce mode, path, cost, and approval gates before dispatch |
| router | choose minimal expert set; avoid sending protected content to unnecessary agents |
| maintainer | update ledgers/drafts only; canonical rules require approval |

## Examples

### Identity reviewer

```text
Use `_Identity` and `_Philosophy` as lenses, not edit targets. Output only consistency checks, risks, and candidate questions.
```

### Visual reference analyst

```text
Use raw images read-only. If a preview is needed, create lightweight derivatives under approved assets or run workspace; never move/rename originals.
```

### Knowledge base builder

```text
Build taxonomy proposals. Do not restructure the vault. Promotion from proposal to vault happens only after Hermes verification and user approval.
```
