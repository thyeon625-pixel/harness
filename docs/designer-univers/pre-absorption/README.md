# Pre-Absorption Package

This package defines the work that must be complete before any Designer_Univers harness artifact is absorbed into the canonical Dropbox workspace.

## Contents

- `absorption-readiness-checklist.md` — human checklist before absorption.
- `absorption-plan.md` — staged plan for moving from fork to Designer_Univers body.
- `dry-run-scenarios.md` — scenarios to test custom harness behavior without touching canonical files.
- `claude-review-request.md` — copy-ready prompt for Claude Code review.
- `hermes-review-protocol.md` — Hermes verification procedure.
- `sample-run-manifest.yaml` — manifest template for System/Runs execution.
- `validation-report.md` — generated by `scripts/designer_univers_validate.py`.

## Current Rule

Fork artifacts are staging outputs. They are not canonical Designer_Univers rules until absorbed through the plan and recorded in ReviewLedger.
